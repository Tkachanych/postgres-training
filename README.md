# PostgreSQL Training

Тренажёр по PostgreSQL для уровня middle+. Практические SQL-задачи, разбор
решений и теоретические заметки. Это не учебный проект с приложением и сборкой:
здесь нет кода, тестов и CI — только задачи, схемы, данные и конспекты.

## Что внутри

| Файл / директория | Назначение |
|---|---|
| `AGENTS.md` | Правила работы тренажёра: роли, режимы, структура уроков, проверка решений |
| `BRIEF.md` | Образец формата постановки задачи — не готовый сценарий |
| `LESSONS.md` | Индекс всех уроков и их статусы |
| `lessons/` | Уроки: условие, схема с данными, решение ученика |
| `THEORY.md` | Индекс теоретических занятий |
| `THEORY_NOTES.md` | Подробные записи теории: выводы, edge-кейсы, вопросы для самопроверки |

## Формат урока

Каждый урок лежит в отдельной директории `lessons/NN-тема/`:

- `task.md` — условие, ожидаемый результат, ограничения и дополнительный вопрос;
- `schema.sql` — идемпотентный DDL с тестовыми данными (`DROP` → `CREATE` → `INSERT` → `ANALYZE`);
- `solution.sql` — решение ученика.

После выдачи или изменения статуса урок фиксируется в `LESSONS.md`.

## Как проходят занятия

1. **Практика** — выдаётся задача без готового решения. Ученик пишет SQL,
   преподаватель проверяет результат, ограничения и план запроса, затем урок
   дорабатывается до полного решения.
2. **Теория** — разбор концепций PostgreSQL без создания урока. После ответа
   задаются вопросы на понимание, а занятие фиксируется в `THEORY.md` и
   `THEORY_NOTES.md`.

## Окружение

Для практики используется PostgreSQL в Docker. Пример для урока 03:

```powershell
# запустить контейнер (если ещё не запущен)
docker run --name postgres -e POSTGRES_PASSWORD=postgres -p 5432:5432 -d postgres:18-alpine

# залить схему урока
docker cp lessons/03-stats-vacuum/schema.sql postgres:/tmp/schema03.sql
docker exec postgres psql -U postgres -d lesson03 -v ON_ERROR_STOP=1 -f /tmp/schema03.sql

# подключиться
docker exec -it postgres psql -U postgres -d lesson03
```

`psql` также можно использовать с хоста: `localhost:5432`, пользователь
`postgres`, пароль `postgres`.
